一套面向**单店**的收银系统：管理后台跑在店里那台 Windows 电脑上，手机或自助收银机通过浏览器连过去收银，数据只落在本机一个 SQLite 文件里，不依赖互联网。

## 包含内容

压缩包里是免安装的绿色版：

| 内容 | 说明 |
| --- | --- |
| `pos.jar` | 后端服务，Spring Boot 3.3.5 + JdbcTemplate |
| `web/` | 前端页面，原生 HTML/CSS/JS，不需要构建 |
| `jre/` | 精简 Java 运行时（约 28 MB），目标机器不装 Java 也能跑 |
| `启动.bat` / `停止服务.bat` | 启停脚本，账号密码与业务数据都在 `data/` |
| `使用说明.txt` | 首次使用的前三步 |

## 运行环境

- Windows 10 / 11 电脑一台，作为店里主机
- 端口 `8080`（电脑、扫码枪）与 `8443`（手机、自助机，走 https 才能调用摄像头）
- 不需要另装数据库，也不需要提前装 Java

## 快速开始

1. 解压到任意目录（别放 C 盘系统目录）
2. 双击 `启动.bat`，浏览器会自动打开 `http://localhost:8080`
3. 首次进后台用默认密码 `admin888`，登录后到「设置」页改掉

手机接入：手机连同一个 Wi-Fi，扫后台「设置」页上的二维码；首次进入给设备起个名字即可开卖。

端口被防火墙拦住时，右键 `放行防火墙端口.bat` 选「以管理员身份运行」；要开机自启就跑 `安装开机自启.bat`。

## 主要功能

| 端 | 能力 |
| --- | --- |
| 收银台 `/pos` | 商品网格与条码搜索、购物车折叠明细、整单折扣、抹零、挂单取单、现金 / 微信 / 支付宝 / 银行卡与组合支付、58 / 80mm 小票打印、交接班 |
| 管理后台 `/admin` | 工作台数据、商品一品多码与 CSV 导入导出、库存出入库与盘点、订单退货红冲、设备权限、报表导出、备份恢复与一键初始化 |

扫码有三条通道互相兜底：USB 扫码枪、手机摄像头（走 https，内置离线 ZXing，不联网也能解）、相册识别或手输。

## 使用前注意

- **备份不要直接拷 `pos.db`**：数据库是 WAL 模式，直接复制可能拿到残库。用后台「设置 → 下载备份」生成一致性快照
- **手机必须走 `https://本机IP:8443`**：安卓 Chrome 在 http 页面上不给摄像头权限
- 证书是启动时自动生成的自签证书，手机首次打开要点「高级 → 继续前往」，离线环境下这是正常现象
- 主机别睡眠，电源选项设成「从不」，否则手机端会断连

## 已知限制

- 单店单主机：多门店汇总不在范围内
- 不做会员与店员账号：身份由设备承担（设备名 + 本地 UUID），没有提成、储值、积分
- 打印依赖浏览器打印对话框，没有内置 ESC/POS 驱动
- 无云端同步，异地备份靠手动
