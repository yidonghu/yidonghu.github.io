直接克隆仓库，删掉 `src/content/` 下的示例文章，改 `src/config/site.json` 里的站点信息即可。

```bash
git clone https://github.com/yidonghu/yidonghu.github.io
cd yidonghu.github.io
npm install
npm run dev
```

没有提取码，也没有二次转载限制，注明来源就行。
